Home Menu
_____________________________________________________

One option on the home menu is "Start Quiz" which is the student login for the app.
This will then take you to select the class you want to quiz for.
Once you click "Begin" the app will start the quiz.

The other option is "Admin Login" which will require a password to enter.
The admin panel has 3 options:
  Add Question:
    Allows the admin to select a category (class) and input a question along with 4 answers and the correct answer. 
  View Questions:
    Allows the admin to see thew current questions and correct answer in a database format.
    Admin can also "edit" or "delete" questions.
  View Scores:
    Allows the admin to see previous quiz scores from students as wel las what category the quiz was in and what questions they missed.
    Admin can also delete quiz scores.
